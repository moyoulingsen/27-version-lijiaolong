黑板：一个行为树所有节点共享一个，当然也只有一个

+ “黑板”是一种简单的键/值存储机制，所有节点都可以共享这一存储空间。
+ Blackboard 中的“条目”实际上是一对键/值组合。
+ 输入端口可以读取 Blackboard 中的数据，而输出端口则可以向 Blackboard 中写入数据。


```xml
<SaySomething name="first"   message="hello world" />
<SaySomething name="second" message="{greetings}" />
<!-- 这个就是想来用greeting对应的黑板值 
当然实际运行的时候这个值可以改变
好在默认情况下，只改变当前这个黑板实例（BlackboardComponent）里的值，不会改变黑板资产（BlackboardData）-->

```

输出节点
OutputPort<std::string>("text")
setOutput("text", "The answer is 42" )

```cpp
class ThinkWhatToSay : public SyncActionNode
{
public:
  ThinkWhatToSay(const std::string& name, const NodeConfig& config)
    : SyncActionNode(name, config)
  { }

  static PortsList providedPorts()
  {
    return { OutputPort<std::string>("text") };
  }

  // This Action writes a value into the port "text"
  NodeStatus tick() override
  {
    // the output may change at each tick(). Here we keep it simple.
    setOutput("text", "The answer is 42" );
    return NodeStatus::SUCCESS;
  }
};
```
