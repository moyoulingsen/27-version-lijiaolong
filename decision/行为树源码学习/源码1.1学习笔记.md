### 依赖注入（Dependency Injection）



```cpp
using namespace BT;

// Simple function that return a NodeStatus
//BehaviorTree.CPP 可以把这种自由函数(不是类的意思)直接包装成行为树节点。
BT::NodeStatus CheckBattery()
{
  std::cout << "[ Battery: OK ]" << std::endl;
  return BT::NodeStatus::SUCCESS;
}




// We want to wrap into an ActionNode the methods open() and close()
//“我们想把 open() 和 close() 这两个方法包装成一个 ActionNode（动作节点）。”
class GripperInterface
{
private:
  bool _open; // shared information
              //下划线 _ 开头，是一种常见约定，表示“内部成员”或“私有变量”
public:
  GripperInterface(): _open(true) {}
                   //成员初始化列表
    
  NodeStatus open() 
  {
	_open = true;
	std::cout << "GripperInterface::open" << std::endl;
	return NodeStatus::SUCCESS;
  }

  NodeStatus close() 
  {
    std::cout << "GripperInterface::close" << std::endl;
	_open = false;
	return NodeStatus::SUCCESS;
  }
};

```

然后我们可以利用这些函子中的任何一个来构建 `SimpleActionNode` 。

​                       **什么是函子** 

​     在 C++ 里，**functor** 狭义上指“重载了 `operator()` 的类对象”，但广义上（尤其在模板和泛型编程里）指：         任何可以像函数一样被调用的东西。

- CheckBattery()
- GripperInterface::open()
- GripperInterface::close()
