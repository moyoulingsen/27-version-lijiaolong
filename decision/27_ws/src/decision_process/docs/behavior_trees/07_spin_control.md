# 任务7：小陀螺控制

## 需求与实现

使用裁判系统 hp_outpost 判断己方前哨状态。未收到有效数据、比赛不在阶段 2、哨兵阵亡或己方前哨仍有血量时强制 spin_mode=0；比赛进行且己方前哨血量为 0 时开启 XML 指定档位。

规则手册只说明自动哨兵底盘功率上限与功率超限惩罚，没有指定小陀螺档位，因此默认选择低速档 1，允许在 07_spin_control.xml 中改为 2 或 3。

该子树是全局控制器，每帧先于主优先级行为执行，因此与巡逻、躲避、补给等任务同时生效。
