# 任务5：巡逻行为

## 需求

比赛进行且更高优先级任务未接管时，哨兵在 XML 配置的点集中往返巡逻。点位使用 x,y;x,y 格式，数量可任意增减，不需要修改 C++。

## 实现

- 默认点集：5,5；9,5；9,9。
- 路径：首点到末点，再沿原路线反向返回首点并循环。
- 巡逻时使用移动姿态，停止射击并清除遗留自瞄目标。
- 导航输出固定 z=1.0、frame_id=map。
- 点位必须位于 28m × 15m 场地边界内。
- 非法字符串、非有限数、空点位或越界点会被拒绝。
- 被更高优先级行为中止时，仅清理仍属于巡逻自身的导航目标。
