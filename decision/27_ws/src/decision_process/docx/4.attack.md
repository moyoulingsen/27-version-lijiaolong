# 进攻逻辑
切换到行走模式
启动中速小陀螺
关闭云台
检测周围地方目标{
    判断是否是无敌状态{是忽略
    否：加入预选攻击目标列表(并且可以预设目标列表（比如3分钟前或前哨站血量》0时前哨站一直是目标）)}

    判断预选攻击列表目标个数

    0目标：切换到防御模式，判断血量和经济{
    血量低于阈值 100 || 经济低于阈值 400 
    启动保守巡逻子树
    反之启动激进巡逻子树
}
    

    多目标：检测在不在射程范围内{
        全部否：启动追击子树
        其他情况：执行下一步
    }
}

根据在射程内的预选攻击目标列表{
    优先血量低于阈值50的优先攻击；
    然后优先距离最近
}

下一步{
    切换至攻击模式
    关闭小陀螺
    启动云台旋转
    判断云台方向和目标是否重合{
        是：关闭云台
        射击
        判断对方血量是否扣血{
            是：SUCCESS继续直到否
            否：开启云台
            返回判断云台方向和目标是否重合
        }
        否：继续旋转云台，若长时间5秒丢失目标，
        切换到行动模式，
        开启中速小陀螺，
        关闭云台
        回到最开始检测环境目标
    }
}


### 躲避行为：哨兵视野内无敌方单位但受到伤害时（以实际场景来说，就是没有看到敌方单位却受到敌方伤害），若且目前已到达目标点（即站定状态），让其动起来以免成为固定靶（即“躲避”），这个“动起来”的效果可以有多种方式实现，自由发挥，但要求伤害解除后（即不受到伤害一段时间后）能回归正常的行为（即不再“躲避”）


进攻逻辑检测周围地方0目标的时候。添加{
    血量检查{
        若血量降低：启动防御模式
        高速小陀螺旋转
        快速移动巡逻路线
        超过五秒未受伤害恢复
    }
}
