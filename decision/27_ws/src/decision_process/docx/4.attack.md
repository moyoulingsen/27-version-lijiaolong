# 进攻逻辑
切换到行走模式
启动中速小陀螺
开启云台扫描
检测周围地方目标{
    判断是否是无敌状态{是忽略
    否：加入预选攻击目标列表(并且可以预设目标列表（比如3分钟前或前哨站血量》0时前哨站一直是目标）)}

    判断预选攻击列表目标个数

    0目标：切换到防御模式，判断血量和经济{
    血量低于阈值 150 && 经济低于阈值 400
    启动保守巡逻子树
    反之启动激进巡逻子树
}
    

    多目标：先通过与云台同轴的 6.2 米探测扇形加入候选，再判断是否进入 4.0 米攻击扇形{
        全部否：启动追击子树
        其他情况：执行下一步
    }
}

根据在射程内的预选攻击目标列表{
    2号工程机器人不加入攻击目标；
    当前识别到的其他可攻击机器人优先于开局持续目标前哨站；
    只要在 6.2 米探测范围内发现血量低于阈值 50 的机器人，该目标获得最高攻击优先级；即使前哨已经在 4 米攻击范围内，也先追击该残血机器人；
    该残血优先级高于低血量回血，即使己方哨兵已低于回血阈值，也先完成追击和击杀；残血目标消失或被摧毁后再恢复回血；
    残血机器人进入 4 米攻击范围后立即切换攻击；
    然后优先距离最近
}
比赛开局前 300 秒内，只要敌方前哨未摧毁，目标 6 始终保留在攻击列表中，即使当前自瞄没有检测到它也不能移除。前哨、残血机器人和其他可攻击单位统一经过攻击树：目标不在检测范围时，前哨使用固定点 `(17.0, 10.0)` 导航；目标进入 6.2 米检测范围但仍在 4.0 米外时执行追击；目标进入 4.0 米攻击范围后停止追击，等待云台对准并开火。前往前哨攻击点以及追击其他目标时保持云台开启扫描。当前识别目标消失或被摧毁后，恢复攻击列表中的下一个任务。
自瞄识别到移动机器人时，决策端只接收以识别时刻相机朝向为极轴的 `target_polar_r`、`target_polar_angle`。通过自身 `map -> camera_link` 位姿变换，将相机相对极坐标换算成 RM 地图绝对坐标，再生成追击导航点。目标仍在自瞄视野内时禁止使用 `radar_data` 替换视觉解算位置，避免行为树获得全场敌方真实坐标；只有自瞄无有效目标时，雷达数据才可进入独立的雷达联动追击逻辑。
追击目标距离大于 4.0 米时开始靠近，目标距离达到 2.8 米时停止靠近；小于 1.2 米时后退，退到 1.8 米停止。前哨攻击点为 `(17.0, 10.0)`，保证与前哨站实际距离小于 4.0 米。

### 躲避行为

1 秒内累计血量下降达到 30，且达到阈值时自身没有检测到敌方单位，锁存回避状态；只有一次 25 HP 的流弹误伤不触发，两次快速 25 HP 扣血累计为 50 HP 后触发。

回避状态执行：
- 切换防御姿态；
- 高速小陀螺；
- 开启云台持续搜索；
- 按约 0.7 秒改变方向的不规则局部轨迹运动，不修改原巡逻点或原攻击任务。

回避期间发现非持续、非无敌且非 2 号工程的目标：
- 自身血量大于目标血量，退出回避并将该目标交给正常进攻逻辑；
- 自身血量不大于目标血量，继续不规则回避。

若自身血量低于回血阈值，回血优先于回避和进攻；连续 5 秒没有再次受到达到 30 的伤害后，解除回避并继续受伤前原本应执行的攻击、补弹或巡逻任务。
