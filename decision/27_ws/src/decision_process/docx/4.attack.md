# 进攻逻辑
切换到行走模式
启动中速小陀螺
开启云台扫描
检测周围地方目标{
    判断是否是无敌状态{是忽略
    否：加入预选攻击目标列表(并且可以预设目标列表（比如3分钟前或前哨站血量》0时前哨站一直是目标）)}

    判断预选攻击列表目标个数

    0目标：切换到防御模式，判断血量和经济{
    血量低于阈值 150 || 经济低于阈值 400
    启动保守巡逻子树
    反之启动激进巡逻子树
}
    

    多目标：先通过与云台同轴的 6.2 米探测扇形加入候选，再判断是否进入 4.0 米攻击扇形{
        全部否：启动追击子树
        其他情况：执行下一步
    }
}

根据在射程内的预选攻击目标列表{
    2号工程机器人不加入攻击目标；
    当前识别到的其他可攻击机器人优先于开局持续目标前哨站；
    优先血量低于阈值50的优先攻击；
    然后优先距离最近
}
前往前哨攻击点以及追击其他目标时保持云台开启扫描。当前识别目标消失或被摧毁后，恢复开局前哨站任务。
追击目标距离大于 4.0 米时开始靠近，目标距离达到 2.8 米时停止靠近；小于 1.2 米时后退，退到 1.8 米停止。前哨攻击点调整为 `(17, 10)`，保证与前哨站实际距离小于 4.0 米。

下一步{
    切换至攻击模式
    关闭小陀螺
    启动云台旋转
    判断云台方向和目标是否重合{
        是：关闭云台
        射击
        判断对方血量是否扣血{
            是：SUCCESS继续直到否
            否：开启云台
            返回判断云台方向和目标是否重合
        }
        否：继续旋转云台，若长时间5秒丢失目标，
        切换到行动模式，
        开启中速小陀螺，
        关闭云台
        回到最开始检测环境目标
    }
}


### 躲避行为

1 秒内累计血量下降达到 30，且达到阈值时自身没有检测到敌方单位，锁存回避状态；只有一次 25 HP 的流弹误伤不触发，两次快速 25 HP 扣血累计为 50 HP 后触发。

回避状态执行：
- 切换防御姿态；
- 高速小陀螺；
- 开启云台持续搜索；
- 按约 0.7 秒改变方向的不规则局部轨迹运动，不修改原巡逻点或原攻击任务。

回避期间发现非持续、非无敌且非 2 号工程的目标：
- 自身血量大于目标血量，退出回避并将该目标交给正常进攻逻辑；
- 自身血量不大于目标血量，继续不规则回避。

若自身血量低于回血阈值，回血优先于回避和进攻；连续 5 秒没有再次受到达到 30 的伤害后，解除回避并继续受伤前原本应执行的攻击、补弹或巡逻任务。
