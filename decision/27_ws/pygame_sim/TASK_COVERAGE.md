本表区分“Pygame 能构造/显示该场景”和“ROS 2 生产决策已经实现”。只有后者完成并通过消息流测试后，才能认为任务真正交付。Pygame 的 `_local_decision()` 仍保留为未启动 ROS 2 时的离线回退；使用 `run_behavior_tree_sim.sh` 时，`_bridge_decision()` 会优先采用 XML 行为树通过 UDP/ROS 返回的输出。

## 尚未完全接入 XML 的边界

当前仍需继续收敛到 `decision_process` 的部分只有：

1. 雷达无视觉目标时的独立追击和拉远策略。
2. 将复活计时、确认复活、补给区解锁整理成独立 XML 子树。
3. 热量/功率限制。目前这些是 Pygame 仿真属性和显示项，ROS 行为树只输出姿态、小陀螺、云台、射击等命令，尚未把热量/功率作为 XML 条件或端口。
